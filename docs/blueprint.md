# **App Name**: PhotoCritique

## Core Features:

- Photo Upload: Allow users to upload photos from their device or take a new photo.
- Instant Photo Review Generation: Generate a detailed review of the photo's qualities: lighting, colors, perspective and overall composition, using AI. Employing an AI tool, it can use reasoning to choose which pieces of information will improve the quality of the critique.
- Review Display: Display the generated text review in a clear, readable format.
- Review Regeneration: Option to regenerate the review for different perspectives or improvements using AI.
- Profile Review Saving: Save the generated review and associated photo to the user's profile for future access.

## Style Guidelines:

- Primary color: Soft green (#A7D1AB), symbolizing nature and serenity.
- Background color: Desaturated soft green (#E0EEE3), providing a calm backdrop.
- Accent color: Warm yellow (#E8CA82), used to highlight key elements and calls to action, with high saturation to add contrast.
- Font pairing: 'Belleza' (sans-serif) for headlines, providing an elegant touch, paired with 'Alegreya' (serif) for body text to improve readability.
- Use minimalist icons with rounded corners, complementing the natural and serene theme.
- Maintain a clean, spacious layout with ample white space to ensure readability and focus on the photos and reviews.
- Implement subtle transition animations for uploading and generating reviews to enhance user engagement.
